Dispatch Control — Uniform System Sheet

The shared vocabulary every page uses. If a surface needs a pattern that isn't here, extend this sheet first, then build it.

House rules
  • Hard edges everywhere. Radius 0–2px. No rounded-lg cards, no rounded-full pills (dots are the only circles).
  • 1c tokens only. Never text-neutral-* / bg-gray-* / text-slate-*. Ink, ink-soft, faint, cobalt, vermilion, marigold, green.
  • Four fonts, four jobs. Newsreader = headlines. Lora italic = deks/excerpts. Space Grotesk = UI. IBM Plex Mono caps = kickers, labels, numerals.
  • Status is never color alone. Chip label + color, or dot + count.
  • Every page head: mono kicker (its nav group) → display h1 → italic dek.
