Two further corrections to the diagnosis:

1. **`contentPatchClient.ts` has TWO broken helpers, not one.** The diagnosis lists it as a single
   site. Site 1 (~line 198) additionally reads `if (Array.isArray(detail?.fields)) fields = detail.fields`
   off the raw body — so the `fields` array on validation errors is *also* silently lost. That line

2. **The project already has a canonical fix for exactly this**, in the 5 correct files. Use it —
   do NOT introduce the `body?.detail ?? body` variant the diagnosis proposes. The two are
   functionally equivalent across every realistic body shape (verified: enveloped dict, plain-string
   detail, 422 array, bare-string body). The established idiom wins on **consistency alone**: a
   reviewer diffing these 8 sibling files should see one idiom, not two near-identical ones.

The established idiom (verbatim from `voicePassClient.ts`):

```ts
      const parsed = await res.json()
      // FastAPI HTTPException wraps dict details as {detail: {reason, message}};
      // fall back to a flat {reason, message} body.
      const detail =
        parsed?.detail && typeof parsed.detail === 'object' ? parsed.detail : parsed
      if (detail?.reason) reason = detail.reason
      if (detail?.message) message = detail.message
      else if (typeof parsed?.detail === 'string') message = parsed.detail
      else if (typeof parsed === 'string') message = parsed
```

Why this satisfies every behavior the diagnosis requires be preserved:
- `{detail:{reason,message}}` → `.detail` is an object → unwrapped → reason/message read. **Fixes the bug.**
- `{detail:"plain string"}` → `.detail` is a string, not an object → `detail` stays `parsed` → no
  reason/message → falls to `typeof parsed?.detail === 'string'` → message = the string. **Preserved.**
- `{detail:[{...}]}` (422) → arrays *are* `typeof 'object'` → unwrapped to the array → no
  reason/message → message stays `HTTP 422`. **Unchanged, as required. Not over-engineered.**
- Non-JSON body → `res.json()` throws → existing `catch {}` → `res.text()`. **Untouched.**
</scope_correction>
