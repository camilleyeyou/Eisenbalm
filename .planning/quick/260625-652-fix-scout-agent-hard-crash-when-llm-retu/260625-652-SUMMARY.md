# Quick 260625-652: Fix Scout Agent Hard Crash on Zero Candidates

One-liner: Removed the escaping `_at_least_one` pydantic field_validator from `ScoutBatchOutput` and added an explicit corrective-retry + descriptive RuntimeError path in `scout()` so a transient empty-candidate LLM response no longer crashes the entire weekly pipeline run.

## Root Cause

The `_at_least_one` `field_validator` on `ScoutBatchOutput.candidates` ran *inside* the OpenAI SDK's `model_parse_json` step (structured-output parse), which is earlier in the call stack than `acomplete`'s error handling. A ValidationError raised there escaped `acomplete`'s corrective-retry path entirely, was caught by the blind `except Exception` in the `@agent_node` wrapper, re-sent the identical messages (retry had no new instruction), failed again, and propagated a crash through the run — observed in Railway run `0b9dba62`.

## Changes

### `packages/pipeline/src/eisenbalm_pipeline/agents/scout.py`

- **Removed** `_at_least_one` `field_validator` from `ScoutBatchOutput` (lines ~83-93)
- **Removed** now-unused `field_validator` import (line 26)
- **Updated** `candidates` field `description` to reflect that empty-list handling is done in `scout()`, not at parse time
- **Added** `_extract_candidates(out)` local helper — DRY extraction used for both the initial parse and the retry re-extraction
- **Added** corrective-retry block after defensive extraction: if `candidates_raw` is empty, logs a warning, appends a strengthened user message to `messages`, calls `acomplete` once more (same interface, reuses existing Tavily results), re-extracts candidates
- **Raises** `RuntimeError("Scout: LLM returned zero charity candidates after one corrective retry (run {run_id}); Tavily surfaced {N} results")` if the retry also yields empty

### `packages/pipeline/tests/agents/test_scout.py`

- **Added** `test_empty_then_populated_retry`: patches `acomplete` with `side_effect=[(empty_batch, USAGE), (populated_batch, USAGE)]`; asserts `call_count == 2` and `len(result["candidates"]) == 3`
- **Added** `test_empty_twice_raises_runtimeerror`: patches `acomplete` with `side_effect=[(empty_batch, USAGE), (empty_batch, USAGE)]`; asserts `RuntimeError` raised and `call_count == 2`
