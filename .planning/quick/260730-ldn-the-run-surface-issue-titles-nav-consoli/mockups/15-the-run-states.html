Rules this surface must keep
  • Never invent an issue. If runs.latest resolves to nothing, say “nothing is running” — do not fall back to a reserved slot.
  • Never contradict the masthead. Both read the same resolution, so they cannot disagree in front of the operator again.
  • Never claim clean while loading. “Nothing needs you” is only truthful once findings, claims and sign-offs have all actually loaded — otherwise show the loading state (the existing ISS-06 discipline).
  • Preserve every issue. The 999xxx issues are real; nothing is deleted. Reserved future slots simply stop being treated as the current run.
