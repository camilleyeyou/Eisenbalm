The run is the page. You land on what the agents produced — real headlines you can read and edit — with state on each, not a task inbox for an issue that has nothing in it. The title leads and the number becomes metadata, so last week’s issue is recognisable at a glance; the title is the run’s chosen subject, already stored in pitchLog (selected: true) and joined server-side, so no schema change and no pipeline change is needed. The switcher lists only issues that have drafts to edit — a scheduled slot with no run is shown greyed and unselectable, never as the current issue. The five stage tabs collapse: reading a section is the Draft stage, and Fact Check / Voice / Approval become the three gates at the bottom.
