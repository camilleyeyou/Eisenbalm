<objective>
Make the dispatch-control `/prompts` section "view-first": the operator sees each
agent's current active prompt (name + preview + version/date on the list, full
read-only pane on the detail page) before any editor opens.

Purpose: Reduce the cognitive cost of editing the wrong thing — show what is
live first, edit on demand.
Output: One additive Convex query, an enhanced list page (client cards with live
previews), and a view-first detail view that preserves all existing editing.
</objective>
