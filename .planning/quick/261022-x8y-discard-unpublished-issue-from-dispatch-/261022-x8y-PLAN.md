<objective>
Let the editor throw away the current unpublished issue from dispatch-control Home. The pipeline deletes the unpublished Sanity `issue-N` docs (plain and `drafts.`) so `_resolve_issue_number` (max+1) hands the next start the same N. The run's step record (Convex runs, agent_runs, pipelineRuns) is kept and shows as Stopped.

Purpose: "We should be able to discard an issue if it does not make sense." (user, 2026-10-22). Today `POST /runs/{id}/cancel` returns alreadyTerminal for ready or held issues.
Output: `POST /runs/{run_id}/discard` + pytest; a `discardRun` client, a "Discard this issue" control on Home + vitest.

No Convex change. No `convex/*.ts` file is touched, so `dev:once` is not needed.
</objective>
