Implement cooperative cancel (RUN-04) and single-section re-roll (RUN-05). Insert the cancel-flag poll into `wrap_agent_node` so a cancelled run stops advancing without tearing in-flight LLM calls, land the run in `runs.status='cancelled'` from `_execute_run`, and add `/runs/{id}/cancel` plus `/runs/{id}/agents/{key}/rerun` to `api/control.py`. Re-roll forks the LangGraph checkpoint, re-runs exactly one section writer, and re-writes the whole Sanity doc from merged state so siblings are byte-identical.

Output: cancel-flag wrapper, terminal cancelled handling, cancel + re-roll endpoints, Convex cancel mutations.
