## Decisions Made

- **D-01 — Two-pin Tavily strategy adopted as-planned:** `langchain-tavily==0.2.18` is the preferred integration; `tavily-python==0.7.24` is the REST client fallback. Sanity-check at install-time confirmed `from langchain_tavily import TavilySearch` works at 0.2.18 — Plan 05-03 can wire `lib/search_client.py` against this path without conditional fallback logic.
- **D-02 — NotRequired over class splitting:** The 7 new ResearchOutput fields use `NotRequired[Optional[T]]` (PEP 655, native in Python 3.11) rather than splitting `ResearchOutput` into a base + `ResearchOutputExtensions(ResearchOutput, total=False)` pattern. Simpler, single-file edit, identical runtime semantics for `TypedDict`.
- **D-03 — `EISENBALM_STUB_MODE=false` documented now, runtime default flips in Plan 05-14:** The .env.example block sets `EISENBALM_STUB_MODE=false` as the documented default (Phase 5 expectation) even though `lib/openrouter_client.py` will still treat absent as `"true"` until Plan 05-14 lands the runtime flip. This keeps the onboarding doc aligned with the target shipped state — engineers reading the file expect the Phase 5 reality.
- **D-04 — selectolax over lxml:** Verified the plan's rationale (CONTEXT D-11) — selectolax ships pre-built wheels (no libxml2 / Docker build complexity on Railway), 4-5x faster on small HTML payloads. Installation succeeded with pure wheel download (2.1MiB).
