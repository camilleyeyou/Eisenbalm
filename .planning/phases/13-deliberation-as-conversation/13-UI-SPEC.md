> `#deliberation` section. Generated by gsd-ui-researcher from CONTEXT.md D-01..D-18,
> RESEARCH.md patterns 1-11, and live codebase reads of `DeliberationSlot.tsx`,
> `globals.css`, `PodcastSlot.tsx`.

> component patterns are fully locked by Phases 9-12. This spec answers ONLY the new
> visual and interaction questions introduced by the conversation thread block.

## Spacing Scale

Declared values (multiples of 4 only — existing codebase convention):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-initial chip letter padding |
| sm | 8px | Turn gap (padding between turn divider and text) |
| md | 16px | Horizontal padding inside the thread wrapper |
| lg | 24px | Vertical margin between thread block and `<details>` machine view below it |
| xl | 32px | `mb-8` top clearance from section divider to thread block |
| 2xl | 48px | Not introduced by this phase |
| 3xl | 64px | Not introduced by this phase |

Exceptions:
- Speaker initial chip: 32px × 32px (`w-8 h-8`) — below 44px but NOT a standalone
  interactive touch target; it is an inline affordance wrapping an `<a>` that has explicit
  `min-height: 44px` (the entire turn row is the target area). This satisfies the ≥44px
  constraint at the row level (CONTEXT.md D-12).
- Turn row itself: `min-height: 44px` enforced via explicit inline style on the wrapping
  `<div role="article">` per turn.
- Speaker chip `margin-top: 2px`: a sub-4px optical-alignment nudge so the 32px chip aligns
  with the first line of body text. Implementation detail only — NOT a grid unit and not
  reused as a design token anywhere else.

Source: `DeliberationSlot.tsx` spacing conventions (`px-4`, `gap-3`, `py-3`, `mt-6 pb-8`).

## Chat Thread — Component Contract

> This section answers the specific design questions for the new inline conversation block.
> Executor must implement exactly as specified here. Every decision cites its locked source.

### Placement

- **Position:** Top of `<section id="deliberation">` — BEFORE the existing `<details>` element
  labeled "How this issue was made."
- **Visibility:** Visible by default. NOT inside a `<details>` accordion (D-09).
- **Anchor:** Reuses the existing `#deliberation` section anchor. NO new anchor added (D-09,
  MED-04 — exactly 8 SectionNavigator anchors must remain).
- **Below thread:** The existing `<details className="deliberation-slot group">` ("How this
  issue was made") is retained byte-for-byte. It sits below the thread block, separated by
  `mb-8` (32px).

### Guard condition

```
{conversation && conversation.length > 0 && ( ... )}
```

If `conversation` is null or empty (old issues, pipeline fallback path), nothing is rendered.
The existing `<details>` machine view fills the section as it does today.

Source: CONTEXT.md D-09, RESEARCH.md Pattern 8.

### Thread container

- `role="log"` + `aria-label="Deliberation conversation"` — appropriate ARIA for a sequential,
  append-only conversation log (screen readers announce additions).
- No explicit `aria-live` region needed (static published content, not streaming).
- CSS class: `del-conversation` (new class added to `globals.css` — follow the existing
  `.del-flow` / `.del-confidence-bar-*` naming convention).
- Max-width: `max-w-[740px]` — matches the prose measure of the Podcast section for visual
  alignment within the wider `max-w-[1340px]` deliberation section shell.
- Top margin: `mb-6` (24px) below any section header label, if added.
- Bottom margin: `mb-8` (32px) between thread and the `<details>` machine view.

### Per-turn anatomy

Each turn in `conversation[]` renders as:

```
┌──────────────────────────────────────────────────────────────────┐
│  [chip]  SPEAKER NAME — Role          (11px / 600 / speaker-var) │
│          turn.text paragraph          (15px / 400 / --color-text-dim) │
├──────────────────────────────────────────────────────────────────┤
│  border-b: var(--color-line-strong), last turn has no border-b   │
└──────────────────────────────────────────────────────────────────┘
```

Layout: `display: flex; gap: 12px; padding-block: 12px` — `py-3 flex gap-3`.

**Left column — speaker initial chip:**
- Size: 32 × 32px (`w-8 h-8`)
- Shape: `rounded-full` (circle)
- Background: `color-mix(in srgb, var(--speaker-accent-var) 14%, transparent)` — mirrors
  `agentChipStyle()` existing formula exactly.
- Content: First letter of `AGENT_LABELS[turn.speaker].displayName` (e.g. "S", "A", "E").
- Font: `font-ui text-[11px] font-semibold` — matching existing chip label style.
- Text color: `var(--speaker-accent-var)`.
- Wrapped in `<a href="/agents/${turn.speaker}">` with `aria-label={label.displayName}` for
  DEL-06 compliance. Min-height of the anchor: use flex + `justify-center` to fill the
  parent row height (the row `min-height: 44px` satisfies the touch target, not the chip alone).

**Right column — name label + text:**
- Speaker name line: `<p>` or `<span>` — `font-ui text-[11px] font-semibold mb-1` —
  color: `var(--speaker-accent-var)`.
- Text: `<p>` — `font-body text-[15px] leading-[1.65]` — color: `var(--color-text-dim)`.
- NO inline Markdown rendering. `turn.text` is ALWAYS rendered as a plain string via
  `{turn.text}` — never via `dangerouslySetInnerHTML`, never via a Markdown parser.
  The DEL-04 tripwire applies to this file; no model names permitted in any string literal
  outside of stripped comments.

**Speaker accent variable mapping (from `agentChipStyle()`):**

| `turn.speaker` | CSS var | Hex |
|----------------|---------|-----|
| `scout` | `--color-scout` | `#8A9B7A` |
| `advocate` | `--color-advocate` | `#6E92B8` |
| `editor` | `--color-primary` | `#CDA434` |
| unknown | `--color-text-dim` | `#A89F8A` |

Call `agentChipStyle(turn.speaker)` exactly — do not duplicate the mapping.

Source: CONTEXT.md D-11, RESEARCH.md Pattern 8, `DeliberationSlot.tsx` `agentChipStyle()` lines 78-101.

### Turn divider

`border-b border-[--color-line-strong]` on each turn container except the last
(`last:border-b-0` via Tailwind).

Source: `globals.css --color-line-strong`.

### Motion contract

- **No entry animation by default** — the conversation is static published content, not
  streaming. Simple render, no stagger.
- If a tasteful stagger-in is desired in a future pass: it MUST be gated on
  `!prefersReducedMotion` (module-scope check, not inside a hook — RESEARCH.md Pitfall 5).
- The existing `const prefersReducedMotion = ...` at module scope in `DeliberationSlot.tsx`
  is the reference; do not redeclare it inside the component function.
- Under `prefers-reduced-motion: reduce`, the `globals.css` block already zeros all
  `animation-duration` and `transition-duration` globally — no per-component override needed.

Source: CONTEXT.md D-12, RESEARCH.md Pitfall 5, `globals.css` `@media (prefers-reduced-motion: reduce)`.

### Empty / null state

If `conversation` is null or `conversation.length === 0`:
- Render nothing — the existing "How this issue was made" `<details>` is the fallback UI.
- Do NOT render an empty state heading or message inside the thread block.

Source: RESEARCH.md Pattern 8 guard condition.

### Section header label (discretionary)

Decision (Claude's Discretion per CONTEXT.md): add a lightweight eyebrow label immediately
above the thread to orient the reader.

```
THE DELIBERATION
```

- Styled: `font-ui text-[11px] uppercase leading-[1.5] tracking-[0.18em]` —
  color `--color-text-dim`. Matches the "The Scout's Candidates — Pitch Log" header in Zone 1.
- Only rendered when `conversation && conversation.length > 0`.
- NOT a new anchor. The `<section id="deliberation">` anchor is the section root.

Source: `DeliberationSlot.tsx` Zone 1 heading pattern ("The Scout's Candidates — Pitch Log").

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| WCAG AA contrast | All new colors are existing house vars verified in prior phases. `--color-text-dim` (#A89F8A) is 7.5:1 on #0C0B0A. `--color-scout` (#8A9B7A) is 6.6:1. `--color-advocate` (#6E92B8) is 6.1:1. `--color-primary` (#CDA434) is verified AA at 11px semibold. No new unverified color values. |

| Semantic HTML | `<section id="deliberation">` wrapper unchanged. Thread block: `role="log" aria-label="Deliberation conversation"`. Each turn is a `<div role="article">` or an implicit block (depending on ARIA best-practice preference — role="article" is acceptable for a named conversation turn). Initial chip anchor: `aria-label={label.displayName}`. |
| Single `<main>` | No new landmark regions. The thread block is inside the existing `<section>` which is inside the existing `<main>`. No structural change to the page landmark tree. |
| `prefers-reduced-motion` | No motion introduced. Existing `globals.css` guard applies. |
| DEL-04 (no model names) | The never-skipped `deliberation-no-model-names.test.ts` tripwire scans `DeliberationSlot.tsx` after comment stripping. No literal `claude`, `gpt`, `sonnet`, `haiku`, `openrouter` may appear anywhere in the file outside stripped comments. New conversation render code is fully subject to this tripwire. |
| Keyboard navigation | Turn chip links are natively focusable `<a>` elements. Tab order: chip link → next chip link (linear, matching DOM order). No JS key-trap. |
| Screen reader | `role="log"` announces the conversation region. Each turn is read in DOM order: chip link (aria-label = agent name) → speaker name paragraph → turn text paragraph. |
| Print | The `<section id="deliberation">` already carries `.print:hidden` via the `deliberation-slot` class in the existing `DeliberationSlot.tsx`. The conversation block inherits this. |

Source: CONTEXT.md D-12, `globals.css` `@media (prefers-reduced-motion)`, `deliberation-no-model-names.test.ts`.
