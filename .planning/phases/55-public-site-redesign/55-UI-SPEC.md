## Spacing Scale

Declared values (all multiples of 4). Mockup values were normalised to the nearest token.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between the four palette dots; inline icon gaps |
| sm | 8px | Chip internal gaps, tight label stacks, button-row gap (compact) |
| md | 16px | Default element spacing; card grid gap minimum; nav link gap |
| lg | 24px | Card padding, stat-tile gap, paragraph gap (18px -> 16px body paragraph margin uses md) |
| xl | 32px | Page gutter at desktop, column gap between prose columns is 48 (2xl) |
| 2xl | 48px | Prose column gap; masthead/hero vertical padding; footer block padding |
| 3xl | 64px | Numbered section vertical padding (top and bottom; mockup 80/88 -> 64/64); back-issues section vertical padding; large block gaps |

Layout rules:
- Content container: `max-width: 1280px; margin-inline: auto; padding-inline: clamp(16px, 5vw, 32px)` (16px at 375px, 32px from ~640px up).
- Numbered section disc: 72px (desktop), 56px below 640px. Pod band disc same. Ticker height 44px. Sticky nav link height >= 48px (16px + 16px padding around 14px text).
- Touch targets: every link, button, input and chip-button has `min-height: 44px` (inline-flex centering). Shared class `.d-tap`. Top-bar links, footer Privacy/Terms, "See them all", and the sticky-nav Fund pill all get `.d-tap`.

Exceptions (documented, not token violations):
- Border widths 1px / 2px / 3px / 4px and the 1px outline on yellow/green dots are strokes, not spacing.
- Component-internal sizes that are not spacing: palette dots 14px, nav dots 10px, hero sticker 150px (fluid: `clamp(112px, 38%, 150px)`), podcast waveform bars 6px wide (decorative), numbered section disc 72px, ticker bar height 44px, game-CTA `min-height` 52px.
- Mockup's 6/10/12/14/18/20/22/28/40/56/72 paddings are normalised to the tokens above (e.g. 18->16, 20->24 for card padding, 28->24, 40->48, 56->48, 72->64, 80/88->64).

## Typography

Font: Manrope. **Four sizes, two weights.** All other mockup sizes (12, 13, 16, 17, 19, 21, 22, 26, 34 ...) are normalised into these four roles.

| Role | Size | Weight | Line Height | Tracking / case | Used for |
|------|------|--------|-------------|-----------------|----------|
| Label | 14px | 800 | 1.35 | `0.08em`, uppercase for eyebrows/section labels; none for nav links and meta lines | Eyebrow pills, section labels ("How it started"), issue/date line, nav links, ticker (uppercase, 0.08em), dt in fact chips, card kind labels (Picked / Runner-up / Also considered), search/newsletter labels, footer legal links, compact buttons |
| Body | 18px | 400 | 1.6 for prose columns; 1.45 for hero dek and card blurbs | normal | Prose columns (`column-width: 340px; column-gap: 48px; column-rule: 1px solid` at the muted tone, only when >=2 columns fit), hero dek, buy-band copy, card blurbs, footer blurb, input text, primary CTA text (800 weight on buttons) |
| Heading | `clamp(28px, 3.6vw, 48px)` | 800 | 1.0 (mockup 0.96; 1.0 chosen so descenders do not clip when text wraps) | `-0.05em` | Section `h2`s, stat figures, pull quotes (weight 400), footer wordmark, pod-band h2. Card titles, nav charity name and back-issue titles use Body 18px at weight 800, not Heading |
| Display | `clamp(40px, 6.2vw, 92px)` | 800 | 0.95 | `-0.055em` | Hero `h1` (charity headline), masthead wordmark ("The Eisenbalm Dispatch", exact Display clamp; constrained by a wrapper `max-width: 12ch` so it wraps to two lines rather than shrinking), buy-band headline |

Weights: **400** (body prose, dek, pull quotes, inputs) and **800** (everything else: labels, headings, buttons, figures, card titles). Mockup weights 300/500/600/700 are normalised: 300 -> 400, 500/600/700 -> 400 or 800 by role (labels and buttons 800, descriptive text 400).

Rules:
- Stat figures (section 02) use the Heading tier; `keyFigure()` caps the figure at ~8 characters, otherwise render the whole stat as a Body sentence (no oversized overflow).
- Long unbroken words (AI-generated charity names, e.g. "Mobilization"): every Display/Heading element gets `overflow-wrap: anywhere; hyphens: auto; min-width: 0`. Clamp minimums (28/40px) plus wrapping are what make 375px safe.
- Pull quotes use the **Heading** clamp exactly at weight 400, highlighted with a `box-decoration-break: clone` background in the section colour.
- Body line-height 1.5 minimum everywhere except Display/Heading.
- Heading hierarchy: one `h1` per page = hero charity headline (the masthead wordmark is a non-heading `p`); section titles `h2`; delib cards, case timeline steps and ad rows `h3`/`dt` as appropriate.

### Accent reserved for (exhaustive)
1. Hero section background (`#story`) and its ink (`inkFor(accent)`)
2. Sticky in-issue nav "Fund them · $8.99" pill background
3. Buy band primary CTA ("Fund them" button) background

Accent is NOT used for: body text, links, focus rings, borders, nav dots (nav dots are fixed per section), section fields (fixed map below), or any control that is not in the list above.

### Weekly accent rotation (deterministic, from `issueNumber`)
- `ACCENT_ORDER = [green #00FF79, blue #005CFF, red #FF002B, yellow #EEFE34]`.
- Index: `idx = ((issueNumber - 2) % 4 + 4) % 4`. This makes **Issue 2 = green**, matching the mockup artboard (research Open Question 4 resolved to mockup-faithful; one constant in `lib/brand.ts`, Andrew can shift it).
- `second = ORDER[(idx+1)%4]`, `third = ORDER[(idx+2)%4]`, `fourth = ORDER[(idx+3)%4]`; emitted as `--d-accent`, `--d-accent-ink`, `--d-second`, `--d-third`, `--d-fourth`, `--d-fourth-ink` by `serializeAccentCss` (values only from the frozen palette; passed through `validateHex`).
- Ink for any palette background = whichever of `#0A0A0A` / `#FFFFFF` has the higher `contrastRatio` (repo function, not the mockup's luminance threshold). Resulting pairs: green->ink 14.69, blue->white 5.28, red->ink 4.98, yellow->ink 17.78. White-on-red is forbidden (3.97).
- Computed inside `IssueLayout` (wrapper carries the CSS vars) so published, home and preview cannot diverge. Back-issue cards recompute their own accent from their issue number.

### Contrast rules (enforced by tests)
- Every text/background pair must be >= 4.5:1 (>= 3:1 only for >=24px bold figures and non-text indicators).
- Focus ring: `.dispatch :focus-visible { outline: 3px solid #0A0A0A; outline-offset: 2px }`; inside black / blue bands use `#FFFFFF`. The global accent-coloured focus ring MUST NOT apply inside `.dispatch`.
- Large-text exception: the section 02 stat numerals in `#EEFE34` (4.7:1) and `#00FF79` (3.9:1) on `#005CFF` qualify only as large text, so they MUST be >= 24px and weight 800 (Heading clamp minimum is 28px). The `dispatch-a11y` test asserts this.
- Colour is never the only carrier of meaning: nav dots and delib card tones are paired with text labels; dots are `aria-hidden`.

## Interaction and State Contract

| Element | States |
|---------|--------|
| Links / pills / buttons | Default; hover = underline on text links; pills invert on hover (ink pill -> white fill with 2px ink border; white pill -> ink fill), 0.15s colour transition, none under reduced motion; no opacity or brightness hover effects; focus-visible ring per Color rules; disabled = `#4A4A4A` fill with white text (never reduced opacity) |
| Sticky nav | Scroll-spy active link (`aria-current`, 3px underline); smooth anchor scroll only inside `@media (prefers-reduced-motion: no-preference)` |
| FundButton | idle -> loading (label "Opening checkout", `aria-busy`, button disabled) -> redirect via `window.location.href`; on failure re-enable and show the existing `CHECKOUT_FAILURE_MESSAGE` inline under the button in an `aria-live="polite"` region (no modal, no toast). Uses shared `startCheckout(1)` |
| All other "Fund them" CTAs | Anchors to `#buy`; only the `FundButton` creates a Stripe session. A "More than one? Choose a quantity" link goes to `/shop` |
| Balm count tile | Server passes initial value; client upgrades via Convex `useQuery`. Value `0` renders "0". Count `undefined` (query not deployed / URL unset) hides the whole tile. No countdown, no scarcity or "only N left", no pulsing |
| Impact bar ("Progress toward the next cart") | Only when `frontPage.impactUnit` exists; fill = `min(balms / ceil(costMin / 8.99), 1)`; ink track `#3A3A3A`, fill `#00FF79`; informational only |
| Back-issues search | Controlled input, case-insensitive trimmed match on name, focusArea, location, `No. {n}`; results announced in an `aria-live="polite"` status line ("{n} nonprofits"); empty-result message shown inside the grid area |
| Newsletter form | Real `<form>` with visible `<label>`, `type="email"` `required`, hidden honeypot field; idle -> submitting (button disabled, label "Sending") -> success or error text in `aria-live="polite"`; always the same generic success text regardless of prior subscription (no enumeration) |
| Game | Click-to-load gate unchanged; `GameFallback` shown when validator rejects |
| Ticker | Marquee; static wrapped under reduced motion |
| Hero sticker | Static 10deg rotation, no animation |
| Preview route (`/issue/[slug]/preview`) | Identical rendering to published (same `IssueLayout`); no extra chrome |

Loading / skeleton: `app/issue/[slug]/loading.tsx` skeleton re-skinned to the Dispatch palette (white page, ink bars, no oxblood). No `ScrollReveal`/opacity-gated entrance animations anywhere (prior opacity:0 bug).

Responsive contract (375px primary check, 311px content width):
- No horizontal page scroll: `document.documentElement.scrollWidth <= innerWidth`. Only the sticky nav link list and (none other) may scroll, and only inside its own container.
- No fixed widths >= 312px: hero art `min(100%, 380px)`; inputs `width: 100%; max-width: 240px`; flex children use `flex: 1 1 min(100%, Npx)`.
- Sticky nav < 640px: charity label hidden, Fund pill compact (Label 14px, `.d-tap`).
- Disc 56px < 640px. Prose columns collapse to one column automatically (`column-width`).
- Desktop parity at >= 1280px: container 1280px, gutters 32px.

Motion: the only continuous motion is the ticker. `prefers-reduced-motion: reduce` disables it and all transitions.
