## Motion Contract

All motion implemented with `framer-motion`. ALL motion gated behind `prefers-reduced-motion: reduce` — when set, all content is immediately visible (no opacity:0, no translateY, no delays).

### Scroll Progress Bar
- `useScroll()` hook → `scrollYProgress` mapped to `width` on fixed bar element
- Under reduced-motion: bar stays at 0% (decorative, acceptable)

### Scroll Reveals (`.rv` equivalent)
- Initial: `opacity: 0; y: 28px`
- Animate: `opacity: 1; y: 0`
- Transition: `duration: 0.9s; ease: [0.16, 1, 0.3, 1]` (cubic-bezier from prototype)
- Trigger: `useInView` with `threshold: 0.2; once: true`
- Under reduced-motion: skip animation entirely (render at final state)

### Stat Count-Ups
- Triggered when briefing center column enters viewport
- Each stat number animates from 0 to `data-to` value
- Duration: ~880ms total (40 steps × 22ms)
- Numbers with `data-plain` attribute: no animation (year values like 1997)
- Numbers with `data-suffix`: append suffix string after final count ("+", "yr")
- Under reduced-motion: render final value immediately (no count)

### Deliberation Message Stagger
- Triggered when deliberation section enters viewport (`useInView threshold: 0.2`)
- Messages: stagger 260ms apart
- Each message: `opacity: 0; y: 14px` → `opacity: 1; y: 0` over 500ms
- After last message: 200ms delay → confidence bar fills to target width, `transition: width 1.6s cubic-bezier(.16,1,.3,1)`
- Under reduced-motion: all messages immediately visible; confidence bar at full width immediately

### Rail Scroll-Spy
- Rail appears when `scrollY > 700px` (framer-motion `useScroll` + conditional)
- Active section: compare section `getBoundingClientRect().top < window.innerHeight * 0.4`
- Active tick: width 18px → 28px, color `#CFC9B8` → `var(--color-accent)`
- Transition: `0.25s` for color/width
- Under reduced-motion: rail still shows/hides but instant transitions

### Ripple Animation (Game Play Button)
- `::before` ring expands from scale(1) to scale(1.6) with opacity 0 → 0 over 2.4s, infinite
- Disabled under `prefers-reduced-motion` (`animation: none`)

### Play Button / Podcast Controls
- Scale/background transitions: 150–250ms
- No framer-motion required (CSS transitions sufficient)
