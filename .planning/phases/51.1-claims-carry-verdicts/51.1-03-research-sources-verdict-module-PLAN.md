```python
class ClaimVerdict(BaseModel):
    claimIndex: int
    verdict: Literal["verified", "contradicted", "unverifiable"]
    evidence: str = ""
    sourceIndexes: list[int] = Field(default_factory=list)

class VerdictBatch(BaseModel):
    verdicts: list[ClaimVerdict] = Field(default_factory=list)
```
- `FACT_CHECK_SYSTEM_PROMPT` (inline constant), exactly:
"You are a fact-checker for a magazine. You receive numbered source passages [S0], [S1], ... and numbered claims [C0], [C1], .... For EACH claim return one verdict:\n- verified: a numbered passage states the claim. Cite it in sourceIndexes.\n- contradicted: a numbered passage directly conflicts with the claim (a different number, date, name or fact). Cite the conflicting passage in sourceIndexes and quote the conflict in evidence.\n- unverifiable: no passage addresses the claim, or the passages are ambiguous.\nNever use outside knowledge. Judge only against the passages given. Do not mark a claim contradicted because a passage omits it — omission is unverifiable. Keep evidence under 300 characters. Return claimIndex, verdict, evidence and sourceIndexes only; sourceIndexes are passage numbers, never URLs."
- `def _build_messages(chunk: list[dict], sources: list[dict], research: dict) -> list[dict[str, str]]`: user content = "SOURCE PASSAGES:\n" + "\n\n".join(f"[S{s['index']}] URL: {s.get('url','')}\nTitle: {s.get('title','')}\nContent: {(s.get('content') or '')[:PASSAGE_PROMPT_CHARS]}" ...) + (if `(research or {}).get("summary")`: "\n\nRESEARCH SUMMARY (context only — not a citable source):\n" + summary[:1500]) + "\n\nCLAIMS:\n" + "\n".join(f"[C{j}] ({row.get('sectionName') or 'unknown'}) {(row.get('text') or '')[:CLAIM_PROMPT_CHARS]}" for j,row in enumerate(chunk)). Passage labels use `s['index']`, and the valid-index set for mapping is `{s['index']: s['url'] for s in sources}`.
- `async def attach_verdicts(run_id: str, claim_rows: list[dict], sources: list[dict], research: dict | None = None) -> list[dict]:`
  1. `rows = [dict(r) for r in claim_rows]` (never mutate input). If not rows: return [].
  2. `now = int(time.time() * 1000)`.
  3. If not sources: for each row set verdict "unverifiable", verdictEvidence NO_SOURCES_EVIDENCE, verdictSources [], verdictAt now (no verdictModel); log.info; return rows. No LLM call.
  4. `url_by_index = {int(s["index"]): s["url"] for s in sources if isinstance(s, dict) and isinstance(s.get("index"), int) and s.get("url")}`.
  5. For each chunk of `CLAIMS_PER_CALL` rows (offset k): `out, usage = await acomplete(agent_id=FACT_CHECK_AGENT_ID, run_id=run_id, messages=_build_messages(chunk, sources, research or {}), response_format=VerdictBatch)`; `verdicts = getattr(out, "verdicts", None) or []` (also accept dict output: `out.get("verdicts")`); iterate; coerce each item via `ClaimVerdict.model_validate(item)` if it is a dict, skip items that fail validation; skip claimIndex outside `range(len(chunk))`; skip a claimIndex already seen in this chunk (first wins); `urls = [url_by_index[i] for i in dict.fromkeys(v.sourceIndexes) if i in url_by_index]`; `verdict = v.verdict`; if verdict in ("contradicted", "verified") and not urls: verdict = "unverifiable" (MANDATORY guard — a hallucinated contradiction is the only way this phase can wrongly block publish; log.info the downgrade); write onto `rows[k + v.claimIndex]`: verdict, verdictEvidence=(v.evidence or "")[:EVIDENCE_MAX_CHARS], verdictSources=urls, verdictAt=now, verdictModel=usage.get("resolved_model") (omit key if falsy).
  6. Do NOT catch exceptions here — `CostCapExceeded` and any other error propagate; the publisher (plan 04) owns the swallow/re-raise policy.
  7. log.info a one-line tally: total, verdicted, per-verdict counts, downgrades, unverdicted.
  Return rows.
