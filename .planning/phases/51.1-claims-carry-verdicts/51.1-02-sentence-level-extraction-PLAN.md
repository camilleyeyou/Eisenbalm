1. Constants:
```python
_ABBREVIATIONS = frozenset({"mr", "mrs", "ms", "dr", "st", "jr", "sr", "inc", "ltd", "co", "no", "vs", "etc", "e.g", "i.e", "u.s", "mt", "ft", "prof", "gov", "sen", "rep"})
_SENTENCE_END = re.compile(r'[.!?]["\'”’)]*(?=\s+|$)')
_MIN_ASSERTION_WORDS = 4
_MIN_FREE_ALPHA_WORDS = 2
_ASSERTION_CONTEXT_CHARS = 300
```
2. `def split_sentences(text: str) -> list[str]:` — walk `_SENTENCE_END.finditer(text)`; for each match take the token immediately before the punctuation (`re.search(r'(\S+)$', text[seg_start:m.start()])`); do NOT split when that token lower-cased with trailing "." stripped is in `_ABBREVIATIONS`, or is a single letter (initials like "J."). Otherwise the sentence is `text[seg_start:m.end()]`; strip ONLY leading/trailing whitespace (so the result is an exact substring of `text`); skip empty. Any trailing remainder after the last split is its own sentence. Returns sentences in order. (A decimal like "2.3" never splits because `_SENTENCE_END` requires whitespace or end-of-string after the punctuation.)
3. `def _assertion_matches(sentence: str) -> list[tuple[int, int, str]]:` — collect `(start, end, type)` from `RE_DATE.finditer` ("date"), `RE_NUMBER.finditer` ("number"), `RE_PROPER_NOUN.finditer` ("proper_noun", skip matches with more than `_MAX_PROPER_NOUN_WORDS` words). Drop a "number" match whose span is fully inside a "date" match span. Sort by (start, type order date<number<proper_noun).
4. `def extract_assertions_by_block(sections: dict, known_entities: Iterable[str] = ()) -> list[dict]:` — iterate `_SECTION_ORDER`, `body` list, skip non-dict blocks, skip `block.get("type") in _HEADING_BLOCKQUOTE`, skip empty text (identical traversal to `extract_claims_by_block`). For each sentence from `split_sentences(text)`:
   - `matches = _assertion_matches(sentence)`; skip if empty.
   - word count `len(sentence.split()) < _MIN_ASSERTION_WORDS` -> skip.
   - free alphabetic words: blank out matched spans (replace chars in each span with spaces), then count tokens matching `^[A-Za-z][A-Za-z'’-]*$` after stripping punctuation; `< _MIN_FREE_ALPHA_WORDS` -> skip.
   - entity-only rule: `known = {_normalise(e) for e in known_entities if e and _normalise(e)}`; if every match is "proper_noun" and each match's `_normalise(text)` either equals a known entity, or a known entity is a whole-word substring of it, or it is a whole-word substring of a known entity (pad with spaces, same trick as `_deoverlap_proper_nouns`) -> skip.
   - dedupe on `_normalise(sentence)` within the block (a `seen` set reset per block).
   - append `{"sectionName": _SECTION_TO_GALLEY_ID[key], "blockIndexHint": bi, "text": sentence, "claimType": matches[0][2], "context": sentence[:_ASSERTION_CONTEXT_CHARS]}`.
   Docstring: one row per assertion sentence; text is an exact substring of the block (so the galley's `resolveSectionFindings` resolves it); no claimIndex (publisher assigns); writer-claimSpan containment is applied by the publisher, not here; no LLM calls.
5. Add `from typing import Any, Iterable` (extend the existing typing import). Update the module docstring's first paragraph with one sentence: "Phase 51.1: `extract_assertions_by_block` is the publisher's extractor (one row per assertion sentence); the token-level functions below are retained for back-compat only."
