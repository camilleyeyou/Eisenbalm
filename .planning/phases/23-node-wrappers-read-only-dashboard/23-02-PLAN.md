<objective>
Instrument every LangGraph agent node with `wrap_agent_node()` so each emits queued→running→done/failed
lifecycle events (with cost-so-far, duration, tokens) to Convex `agent_runs`, plus a truncated I/O snapshot
to `agent_run_payloads`. Cost is READ from the existing `cost.py` per-agent store — never re-recorded.
Pre-populate all agent_runs rows as `queued` at run start so the graph view shows the full pipeline shape
immediately.

Purpose: This is the live-progress producer (OBS-03), the cost surface (OBS-04), and the I/O capture (OBS-05).
The HIGHEST-RISK pitfall is double-counting cost; this plan reads only.
Output: agent_wrapper.py, builder.py wiring across all nodes, queueForRun at run start, and a pytest spec.
</objective>
