> Planner note — D-12 path correction (rational override of locked decision):
>
> D-12 in CONTEXT.md says `schema: { path: './sanity.types.ts' }` — this is a typo from the discussion stage. Per Sanity v5 CLI docs, `schema.path` is the JSON extract destination consumed by `sanity schema extract` (not the TypeScript output path). The correct value is `'./schema.json'`. The TS output `sanity.types.ts` is emitted by `sanity typegen generate` to the package root by default and does not need to be configured via `schema.path`. This plan deliberately uses `'./schema.json'` for `schema.path` and relies on the typegen default for the TS output. The override is documented in the SUMMARY for traceability.
</objective>
