## Color

### Light Palette Philosophy

The dark palette was built on `#0C0B0A` (near-black canvas). All derivations assumed darkness: text-dim / text-mute tones were brightened for dark-background legibility, agent identity colors were pastel-desaturated to lift off black, and atmosphere glows used near-invisible low-opacity mixes against the black background.

The light palette inverts every assumption: text tones are darkened for ink-on-paper legibility, agent identity colors are deepened to contrast on white, atmosphere glows become gentle paper-ink washes, and "bright" derivations that previously mixed toward white must now mix toward black (deeper/darker).

The single fixed-palette architecture is unchanged — DesignAgent stays suppressed, per-issue theming stays off.

### 60 / 30 / 10 Distribution

| Role | Hex | Usage Share |
|------|-----|-------------|
| Dominant (60%) | `#FAFAF8` | Page background, html body |
| Secondary (30%) | `#F2EFE9` + `#EDE9E1` | Elevated surfaces, cards, nav, audio figure |
| Accent (10%) | `#CDA434` + `#C2502A` | Decorative fills, borders, active states, progress bar |

Accent `#CDA434` (brand gold) and `#C2502A` (brand rust) are reserved for:
- Decorative section markers and ornaments (`.ornament-divider`)
- Active navigator node dots and spine fill
- Drop-cap initial letter color
- Left-border accent on mission statement
- `.del-confidence-bar-fill`
- `.progress` scroll-progress bar
- Focus ring (`:focus-visible outline`)
- Hover border on section cards and PDF download button
- Large-text / icon / border usage ONLY — NEVER as normal body-text color on `#FAFAF8` (gold fails AA at normal text size on light; see table below)

## Effect Reconciliation Rules

### Atmosphere — `.aurora` Radial Gradients

**Current (dark):** Three radial-gradient ellipses at 10% / 6% / 4% of their respective color mixed with transparent, on a `#0C0B0A` black canvas. At those opacities, glows are visible warm halos against black.

**Light rule:** On `#FAFAF8`, the same color-mix percentages produce amber/rust muddy blobs rather than elegant glows. Reduce all radial-gradient color intensities by ~50–60%.

```css
/* Light aurora — replace ONLY the percentage values in color-mix() */
background:
  radial-gradient(
    ellipse 90% 55% at 50% -12%,
    color-mix(in srgb, var(--color-primary) 5%, transparent),   /* was 10% */
    transparent 70%
  ),
  radial-gradient(
    ellipse 70% 45% at 85% 8%,
    color-mix(in srgb, var(--color-accent) 3%, transparent),    /* was 6% */
    transparent 65%
  ),
  radial-gradient(
    ellipse 60% 50% at 10% 30%,
    color-mix(in srgb, var(--color-advocate) 2%, transparent),  /* was 4% */
    transparent 60%
  );
```

Net effect: a barely-there warm-paper blush at the top of the page, not a glowing dark aurora.

### `.grain` overlay

No change to the `.grain` rule. `opacity: 0.045` on a paper background reads as slight paper texture — correct and intentional.

### `.bg-grid`

No change to the `.bg-grid` rule. `--color-line` is a 8%-opacity mix of `--color-text` (now ink on paper) = delicate column guides on paper. `opacity: 0.4` is correct.

### `.progress` scroll bar

`background: linear-gradient(90deg, var(--color-primary), var(--color-primary-bright))` — uses brand gold and the bright (now deeper) gold variant. Box-shadow uses `--color-primary-glow` (now 12% instead of 40%). No code change needed — the token values drive the appearance.

### Section Card Hover Shadow

**Current (dark):**
```css
box-shadow:
  0 24px 60px -20px rgba(0, 0, 0, 0.7),    /* heavy dark drop-shadow */
  0 0 0 1px color-mix(in srgb, var(--color-primary) 20%, transparent);
```

**Light replacement:** Dark drop-shadows are visually wrong on paper (a black shadow under a warm card is jarring). Use a warm paper shadow instead.

```css
box-shadow:
  0 8px 32px -8px rgba(90, 75, 50, 0.18),  /* warm sepia shadow, paper-appropriate */
  0 0 0 1px color-mix(in srgb, var(--color-primary) 20%, transparent);
```

Same applies to `.snw-node.active` glow:
```css
box-shadow: 0 0 8px color-mix(in srgb, var(--color-primary) 30%, transparent);
/* was color-mix(... var(--color-primary-glow)), which is fine — the reduced glow token covers this */
```

### Deliberation `.del-conversation` Chat Thread

The `.del-conversation-chip` circle and text use `agentChipStyle()` in `DeliberationSlot.tsx` which returns `color: var(--color-scout)` / `var(--color-advocate)` / `var(--color-primary)` and `backgroundColor: color-mix(in srgb, var(--color-*) 14%, transparent)`.

- On light background, `--color-scout` = `#3D6B2E` (6.01:1 on white) → 14% tinted chip background ≈ warm moss wash. Legible, editorial.
- `--color-advocate` = `#1B4F8A` (7.94:1) → 14% navy wash. Legible.
- `--color-primary` for editor chip = `#CDA434` at 14% = very subtle gold wash. The chip text `color: var(--color-primary)` = `#CDA434` on `#FAFAF8`. This is only the CHIP INITIAL LETTER (11px uppercase) — this must be updated to `var(--color-primary-text)` (`#7A5C0E`) for the chip label text.

Reconciliation action: In `DeliberationSlot.tsx` `agentChipStyle()`, for the editor branch, change chip text color from `var(--color-primary)` to `var(--color-primary-text)`. Scout and advocate branch text color is `var(--color-scout)` / `var(--color-advocate)` (now deep moss / deep navy) — these pass AA on light, no change needed.

Similarly: the turn speaker name `p` tag in the chat render uses `chip.color` (same agentChipStyle output). The 11px label text for editor speaker uses gold — must use `--color-primary-text`.

### `.del-conversation-turn` border

`border-bottom: 1px solid var(--color-line-strong)` — on light, `--color-line-strong` = 16% ink on paper ≈ `#D8D4CC`. A very subtle warm rule. Visually correct — lighter than deliberation zone 2 connectors, heavier than hairline.

### `.del-confidence-bar-track`

`background: var(--color-line-strong)` — on light, the bar track becomes a warm light gray. `.del-confidence-bar-fill` uses `var(--color-primary)` (gold fill). Gold bar on light gray track — visually correct, high contrast editorial.

### IssueHero Ghost Numeral

`opacity: 0.025` — on dark: near-invisible warm numeral. On light: also near-invisible. 0.025 is correct for both. The ghost numeral is `#F0EAD9` → NO, it references `var(--color-text)`. On light `var(--color-text)` = `#1A1A1A`. At opacity 0.025 a near-black glyph on paper — still a subtle ghost. Correct, no change.

### IssueHero H1 text-shadow

`textShadow: '0 0 80px var(--color-primary-glow, rgba(205,164,52,.12))'` — the fallback is already at `.12` opacity. With `--color-primary-glow` reduced to 12% mix on the light palette, this will be a barely-visible warm halo. Correct for paper.

### `--color-text-muted` / `--color-border` aliases

`--color-text-muted: var(--color-text-mute)` → now `#706860` (5.24:1 on `#FAFAF8`). Passes AA. `--color-border: var(--color-line)` → 8% ink hairline. No text AA requirement for borders.
