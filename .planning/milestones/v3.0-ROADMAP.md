# Milestone v3.0: Dispatch Control v2 — Editorial Operator Console

**Status:** ✅ SHIPPED 2026-07-10
**Phases:** 30–39
**Total Plans:** 62

## Overview

Rebuilt `apps/dispatch-control` into the complete editorial surface (committed 1c "bold anti-SaaS magazine" design), so Andrew reviews, edits, de-slops, and publishes an entire weekly issue from the dashboard — with Sanity reduced to a pass-through datastore and Studio retired to a read-only fallback. Ten phases: a design-system + chrome foundation (30), a scoped content-patch write boundary + full editing (31), a native `@portabletext/react` galley with an inline span-resolver (32), accept-fix wiring + a blockers-first decision rail (33), a two-sign-off publish gate that closes the Studio bypass (34), an end-to-end provenance pipeline with sourced/unsourced galley rendering (35), a dedicated Voice Pass de-slop screen (36), a forensic Run Monitor v2 + Signal Desk with Gate 1 adjudication (37), Prompt Lab evals + an Eval Center drift detector (38), and a Registry coverage-memory strip with a Researcher-reused corrections log (39). Phases 37–38 ran as parallel tracks with no schema/endpoint dependency on the Review Desk track (30–36).

## Milestone Summary

**Stats:** 10 phases · 62 plans · 2026-07-06 → 2026-07-10 (5 days) · 335 commits · 467 files changed (+59,480 / −2,833).

**Parallel tracks:** Phases 37 (Run Monitor v2 + Signal Desk) and 38 (Prompt Lab Evals + Eval Center) were built as independent tracks over existing backend substrate with no schema/endpoint dependency on the Review Desk track (30–36).

**Key Decisions:**

- **Sanity bypass, not removal** — dispatch-control replaces Studio for all editing/publishing this milestone; Sanity stays as the datastore. Full removal (content → Convex, assets → blob, web data-layer swap, Studio deletion) is a deferred follow-up milestone, gated on real weekly cycles proving the dashboard.
- **Write boundary: dashboard → pipeline API → Sanity** for every content mutation, each logged to `audit_log` ("nothing silent") — the isolation that makes the later Sanity removal a contained adapter swap. EDT-05 source-scan enforces zero direct Sanity writes from the console.
- **Galley is native, not an iframe** — inline annotations require span control; the web preview route was retained as a reader-fidelity fallback for one full weekly cycle.
- **Contract-first discipline** — API_CONTRACTS.md amended (§31/§33/§34/§35/§38) BEFORE any producer/consumer code, per the CLAUDE.md hard rule.
- **Provenance is index-bound, not fuzzy-matched** — writers reference claim IDs in structured output at generation time, so source bindings survive rewriting rather than being reconstructed post-hoc.
- **Two-sign-off gate + webhook re-validation** — "Facts cleared" + "Sounds human" are both server-enforced, and the publish webhook itself re-checks sign-off state so the Studio status-flip can no longer bypass the gate.

**Issues Resolved:**

- Closed the Studio status-flip publish bypass (PUB-02) that previously skipped all gates.
- Fixed the deployed dashboard's dead test-run panel — `NEXT_PUBLIC_PIPELINE_URL` configured + Railway CORS verified live (CHR-05).
- Upgraded regex-only `claim_checks` into source-bound per-claim provenance surviving into prose (PRV-01..04).

**Technical Debt / Deferred:**

- **Studio deletion** and the full Sanity-removal follow-up milestone (content → Convex, assets → blob, web data-layer swap) remain deferred until the dashboard has proven itself over real weekly cycles.
- **Signal Editor agent + REAL/OBSCURE/SPECIFIC/TELLABLE gates** deferred — Signal Desk shipped over existing backend only.
- **Suno + NotebookLM API automation** (V3-DEF-05) deferred — manual upload flows ship in EDT-03.
- Open human/visual UAT items persisted per phase in `*-HUMAN-UAT.md` / `*-VERIFICATION.md` (e.g. galley visual fidelity, live iframe-fallback paths, repeat-charity corrections-reuse confirmation) — surfaced via `/gsd:audit-uat`.
