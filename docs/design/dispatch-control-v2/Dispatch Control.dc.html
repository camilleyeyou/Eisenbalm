How to use

One editor, a full masthead. Here's the loop and the rules.

The weekly loop

The pipeline does the legwork; you make the calls. Five moments, in order. Anything waiting on you always shows up in the Awaiting you chip, top-right, from any screen.

1
Steer discovery · Signal Desk

Read the three signals, pin or kill any, and adjudicate the Gate 1 winner. If two candidates tie or a brand-risk shows up, the screen enters interrupt mode — pick, and your reason is logged to the transcript and remembered next week.

2
Watch the run · Run Monitor

Agents are dots, the three deterministic checks are ◆ gold diamonds. Click any node to read exactly what it handed downstream (human-readable first, JSON behind a toggle). Don't like a step? Re-run from this node with new steering — everything after it re-flows.

3
Clear the facts · Review Desk

Read the issue as the reader will. Every error in the rail must be resolved — Accept fix, edit inline, or dismiss with a one-line reason. Marigold underlines are sourced claims (hover for the source); a rust tint means unsourced. Publish stays locked until the blocking list is empty.

4
De-slop it · Voice Pass

The one thing only you can do. Machine-tells are lit inline; accept a rewrite, write your own, or keep it. When it reads like a person wrote it, hit Sounds human — a sign-off separate from the facts. Publish needs both greens.

5
Improve the machine · Prompt Lab + Eval Center

Between issues, edit a prompt, run evals on just the affected scenarios, and commit only if the scoreboard improves with no regressions (or override with a logged reason). Run a shadow against real news before ever paying for a live run.

What the colors mean

Verified / cleared — a check ran and passed
Error / blocking / unsourced — needs you
Warning / sourced-claim / code gate
Interactive / links / the current selection

Four house rules

Silence is never "verified." A check that ran says so, with a timestamp. Blank means unchecked, and unchecked is a state you can see.
Nothing silent. Every dismiss, overrule, and kill needs a one-line reason, logged where the next agent — or the next you — will read it.
JSON is never the default. Every artifact has a human-readable face. The raw data is one toggle away when you want it.
The irreversible ones ask twice. Publish, blocklist, and turning auto-publish on take a typed confirmation. Everything else is one click and an undo.
